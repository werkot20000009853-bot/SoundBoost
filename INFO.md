# SoundBoost — информация о приложении

**Версия:** 1.2.0  
**Платформа:** Windows 10 / Windows 11 (64-bit)  
**Назначение:** усиливать системный звук компьютера громче стандартных 100 %.

---

## Кратко

Windows не даёт выкрутить громкость выше 100 %. SoundBoost перехватывает аудиопоток,
умножает его на выбранный коэффициент (до 500 %) и выводит усиленную копию на
динамики или наушники. Работает с музыкой, видео, играми, браузером, Discord —
со всеми программами, которые издают звук.

Приложение полностью автономно: готовый `.exe` не требует Python, библиотек
или интернета.

---

## Возможности

- **Усиление 100–500 %** в реальном времени с ползунком и пресетами.
- **Софт-лимитер** — защищает от клиппинга и искажений на высокой громкости.
- **Два режима работы:**
  - *Устройство* — классическая схема через WASAPI Loopback (нужен второй выход
    или виртуальный аудиокабель);
  - *Приложение (без эха)* — захват звука только выбранной программы через
    Windows Process Loopback (Windows 11 / Windows 10 build 20348+).
- **Микшер приложений** — отдельная громкость и кнопка mute для каждой
  запущенной программы.
- **Системная громкость** — ползунок, кнопка «Максимум», без звука.
- **Авто-настройка** — сама подбирает «тихий» выход как источник и возвращает
  усиленный звук на реальные динамики; есть кнопка отката настроек.
- **Защита от проблем:**
  - блокируется запуск, если источник и вывод — одно устройство (иначе эхо);
  - переключатель «Заглушить оригинал» убирает удвоение звука;
  - выбор буфера 10/20/40 мс и повышенный приоритет DSP убирают треск.
- **Русскоязычный интерфейс**, сохранение всех настроек, встроенная инструкция.

---

## Как это работает

1. Звук с выбранного источника (второго выхода, виртуального кабеля или
   конкретной программы) попадает в приложение.
2. DSP-поток снимает аудиобуфер, умножает сэмплы на коэффициент усиления,
   применяет мягкий лимитер и отдаёт результат в выходной поток.
3. Усиленная копия идёт на ваши динамики/наушники.

Для подавления щелчков используется буфер, выровненный по периоду аудиоустройства
(480/960/1920 сэмплов при 48 кГц), а поток обработки запускается с повышенным
приоритетом.

## Системные требования

| Параметр | Требование |
|---|---|
| ОС | Windows 10 (64-bit) или Windows 11 |
| Звук | Любой рабочий выход (динамики, наушники, HDMI, Bluetooth) |
| Для старых сборок Windows | Виртуальный аудиокабель, например VB-Cable |
| Для режима «Приложение» | Windows 11 / Windows 10 build 20348+ |
| Место на диске | ~70 МБ |
| Python | **Не нужен** (для готового exe) |

Узнать сборку Windows: `Win + R` → `winver`.

## Установка

1. Скачайте архив последней версии со страницы релизов:
   https://github.com/werkot20000009853-bot/SoundBoost/releases
2. Распакуйте в любую папку (например, `C:\SoundBoost`).
3. Откройте `SoundBoost.exe`.
4. Разрешите доступ, если Windows спросит (приложение работает только со звуком).

Папку `SoundBoost` нельзя разделять: рядом с `SoundBoost.exe` лежит папка
`_internal` со всеми библиотеками.

## Использование

### Если у ноутбука один выход и стоит VB-Cable

1. В Windows назначьте **Cable Input** устройством вывода по умолчанию.
2. В SoundBoost оставьте режим **«Устройство»**.
3. В поле «Источник» выберите `Cable Output [Loopback]`.
4. В поле «Вывод» выберите ваши реальные динамики/наушники.
5. Нажмите **«ВКЛЮЧИТЬ УСИЛЕНИЕ»**, запустите музыку и подберите процент.

### Если есть два выхода (например, HDMI-монитор и динамики)

1. Нажмите **«Авто-настройка»** и подтвердите смену устройства по умолчанию.
2. Нажмите **«ВКЛЮЧИТЬ УСИЛЕНИЕ»**.
3. Подберите усиление ползунком.

### Если у вас Windows 11 / новая сборка Win10

Можно не ставить кабель: выберите режим **«Приложение (без эха)»**, запустите
музыку, нажмите «Обновить список», выберите программу и включите усиление.

## Настройки

| Настройка | Что делает |
|---|---|
| Усиление | Основной коэффициент, 100–500 % |
| Лимитер | Мягко ограничивает пики, защищая от искажений |
| Буфер | 10 мс — меньше задержка, 40 мс — стабильнее при треске |
| Высокий приоритет DSP | Снижает риск подрывов аудиобуфера |
| Заглушить оригинал | Убирает одновременное звучание обычной и усиленной копии |
| Громкость приложений | Индивидуальные ползунки и mute для каждой программы |

## Решение проблем

**Эхо/гул.** Вы захватываете и выводите на одно и то же устройство. Запуск таких
конфигураций заблокирован. Используйте виртуальный кабель, второй выход или
режим «Приложение (без эха)».

**Треск/щелчки.** Поставьте буфер 40 мс и перезапустите усиление. Проверьте,
что частота устройства кабеля и динамиков одинакова (обычно 48 кГц) в
«Дополнительных параметрах звука» Windows.

**Звук пропал в режиме «Приложение».** Отключите «Заглушить оригинал» —
захват приложения на некоторых системах может зависеть от громкости сессии.

**Приложение не запускается на старой Windows.** Режим «Приложение» требует
Windows 11 / Win10 build 20348+. Используйте VB-Cable и режим «Устройство».

**Искажения на большой громкости.** Уменьшите усиление до 150–200 % и
убедитесь, что лимитер включён.
