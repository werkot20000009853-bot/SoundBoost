# SoundBoost — усилитель системного звука для Windows

Приложение усиливает звук всех программ Windows до **500 %** (вместо стандартного
ограничения 100 %) и показывает удобный микшер громкости.

## Как запустить

**Готовый exe (без установки Python):** откройте `dist/SoundBoost/SoundBoost.exe`
(или ярлык `SoundBoost.lnk` в этой папке). Папку `dist/SoundBoost` нельзя
разбивать — внутри лежит `_internal` с библиотеками.

**Из исходников:** `python soundboost.py` или двойной клик по `Запуск SoundBoost.bat`.

## Ноутбук с одним выходом (режим без эха)

Если динамик только один, обычный loopback замыкает звук сам на себя и
появляется эхо. Для такого случая есть режим **«Приложение (без эха)»**:

1. Переключите переключатель в блоке «Маршрутизация звука» на
   **«Приложение (без эха)»**.
2. Запустите музыку/видео и нажмите **«Обновить список»**.
3. Выберите программу (или **«Все приложения»**) и устройство вывода —
   ваши динамики.
4. Нажмите **«ВКЛЮЧИТЬ УСИЛЕНИЕ»** и подберите процент (обычно 150–250 %).

Звук берётся напрямую из выбранной программы через Windows Process Loopback,
поэтому усиленная копия не попадает обратно в захват — эха нет. Оригинальный
звук программ при этом заглушается (переключатель **«Заглушить оригинал»**),
чтобы не было удвоения; если звук исчез — отключите его.

> Режим требует **Windows 11** или **Windows 10 build 20348+**. На более
> старых версиях приложение покажет сообщение и предложит виртуальный кабель.

## Два выхода / режим «Устройство»

1. Нажмите **«Авто-настройка»**. Приложение найдёт второй выход (например,
   HDMI-монитор или наушники), сделает его источником звука и направит
   усиленный поток на ваши реальные динамики. Понадобится подтверждение —
   Windows сменит устройство вывода по умолчанию.
2. Нажмите **«ВКЛЮЧИТЬ УСИЛЕНИЕ»**.
3. Включите музыку/видео и подберите ползунок **«Усиление»** (обычно 150–250 %).
4. При искажениях включите **лимитер** или уменьшите процент.

Запуск с одним и тем же устройством захвата и вывода заблокирован —
используйте режим «Приложение (без эха)» или виртуальный кабель.

Кнопка **«Восстановить вывод»** вернёт прежнее устройство по умолчанию.
Настройки запоминаются автоматически.

## Альтернатива: виртуальный кабель

Если второго физического выхода нет:

1. Установите VB-Cable (VB-Audio Virtual Cable).
2. В Windows назначьте **Cable Input** устройством вывода по умолчанию.
3. В SoundBoost выберите:
   - источник — `Cable Output [Loopback]`;
   - вывод — ваши динамики/наушники.
4. Включите усиление.

## Возможности

- усиление 100–500 % в реальном времени (WASAPI loopback → DSP → вывод);
- режим «Приложение (без эха)» на ноутбуке с одним динамиком (Windows Process Loopback);
- софт-лимитер, защищающий от клиппинга;
- ползунок системной громкости и кнопка «Максимум»;
- список запущенных приложений с индивидуальной громкостью и кнопкой mute;
- автообновление микшера каждые 2,5 с;
- русскоязычный интерфейс, сохранение настроек в `soundboost_settings.json`.

## Ограничения

- Нельзя использовать одно и то же устройство и для захвата, и для вывода —
  возникнет обратная связь (эхо). Приложение предупредит об этом.
- DSP добавляет задержку ~20–40 мс. Для игр и голосовых звонков лучше
  обычная системная громкость без усиления.
- На этой машине аппаратный буст недоступен (максимум 0 dB), поэтому
  применяется программный DSP, описанный выше.
